# The self-check

The self-check reads the scale again with every change and lists what looks like a scoring error. It warns and never blocks.

Each finding is a **Check** (probably an error) or a **Note** (worth knowing, not an error in itself). For each one you can:

- **Fix it** in one step, where a fix exists.
- **Keep as it is**.
- **Does not apply**, with a reason the scale keeps.
- **As published**: the original publication has it this way. Write what the original says (and its page), then either **Keep as printed** or **Correct it**, which makes the fix and records it as a change from the published measure.

Decided findings can be reopened. Open findings and source notes print in the researcher copy; the respondent copy is unchanged.
