# Importing a stored scale

**Import stored scale** reads a scale you already have as a Word file (.doc or .docx) or a text file (.txt): its title, instructions, response scale, items, recode line, subscales and source.

Everything the importer found opens on [the scale form](topic:scale-form) to confirm and correct. Fields it was unsure of are marked **Check**, with a list at the top saying how sure it was. Lines it did not understand are listed at the bottom; copy anything you need into a field, then clear the list.

A file that holds more than one scale asks which to confirm first; import the file again for the others.
