# Keyboard shortcuts

| Keys | What they do |
| --- | --- |
| Ctrl+S | Save the scale, or the questionnaire on the Questionnaire tab |
| Ctrl+Shift+S | Save as |
| F8 | Go to the next field the importer was unsure of |
| F1 | Open Help |
| Left and right arrows | Move between the tabs when a tab has the focus |

Every button, including the arrow buttons that reorder items and questionnaire boxes, works with Tab and Enter.
