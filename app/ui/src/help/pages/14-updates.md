# Updates

**Check for updates**, below, asks the project's release page whether a newer version of Prism Survey has been published. It sends only what any web request sends: the program's version and the kind of computer. Nothing is downloaded or installed without your go-ahead.

**Check for updates once a day** is off unless you turn it on. When it finds a newer version, it only announces it.

Installing downloads the installer, checks that it carries the maintainer's update signature (a file that does not match is refused), then closes Prism Survey and runs the installer. Save your work first. **Return to the previous version** installs the version before, checked the same way.

A copy built before updates were set up says so and connects to nothing.
